## 🚀 Featured Project

### [Olist Lakehouse Analytics](https://github.com/ojonathanluis/olist-lakehouse-databricks)

End-to-end analytics project built with **Databricks, PySpark, SQL, Delta Lake and Power BI**, following a simple Medallion Architecture.

**Pipeline**

```text
CSV Files
   ↓
Unity Catalog Volumes
   ↓
Bronze — PySpark + Delta Lake
   ↓
Silver — SQL
   ↓
Gold — SQL
   ↓
Power BI
```

**What the project demonstrates**

- Automated ingestion of multiple CSV files with PySpark
- Delta tables in Databricks
- Bronze, Silver and Gold data layers
- SQL transformations and analytical joins
- Basic data validation and business rules
- Power BI connected to the Databricks analytical layer
- Sales and logistics KPIs

> The project was intentionally kept simple and transparent so every step of the pipeline can be understood and explained.
